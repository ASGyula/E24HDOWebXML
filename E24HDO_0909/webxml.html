Webes adatkezelő környezetek

Oktató: Dr. Bednarik László
Kredit: 5

Tematika:

1. XML nyelv áttekintése; XML kialakulása; helyesen formált XML, névterek ls szimbólumok; DTD séma
2. XMLschema szerepe, áttekintése, séma elemek: jelölő elemek és típusok megadása;
3. Összetett XMLschema séma elemek: származtatott típusok, megszorítások.
4. DOM API szabvány szerepe, működése; XML feldolgozás lépései Java DOM környezetben; XML módosítási funkciói; XML szerializálása.
5. Az XPath szabvány kezelése, Xpath szerepe, elemi Xpath komponensei; összetett XPath használata; XPath függvények.
6. XSLT nyelv szerepe; XSLT minta megadási módok; XSLT transzformációs parancsok, ciklusok, elágazások; Összetett XSLT transzformációs parancsok,
7. JSON formátum áttekintése; helyesen formált JSON; JSON séma elemei; JSON-XML konverzió
8. JSON API szerepe, áttekintése; JSON parser funkciók Java, JavaScript, Python környezetben, GSON feldolgozó.
9. Kliens oldali adat perzisztencia lehetőségei, localstore mechanizmus működése és programozása; IndexedDB mechanizmus működése és programozása;
10. Szerver oldali DB adat perzisztencia, SQL és noSQL modellek, CAP tétel, tranzakciók
11. Felhő alapú adatkezelés architektúrája; Oracle Cloud használat áttekintése, Docker adatbázisok, Cloud alapú adatelérés gyakorlása Java-ból,
12. Adatbázis API-k áttekintése, JDBC, ORMS, Restful APOI és GraphQL
13. Elosztott DBMS rendszerek és MapReduce architektúrák; MapReduce funkcionális modellje, keretrendszerei
